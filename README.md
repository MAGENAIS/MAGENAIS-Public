# MAGENAIS

**Where Every Intelligence Works Together**

MAGENAIS is a closed-source, modular Generative AI Operating System (GENAI OS) that unifies cloud AI providers, local/browser AI, and intelligent workflows into a single browser-based platform — no installation required.

**Live app:** this repository is deployed automatically via GitHub Pages.

---

## What You Can Do with MAGENAIS

- ✍️ **Text Generation** — writing, translation, summarization, coding, reasoning, and conversational AI
- 🖼️ **Image Generation & Editing** — create, enhance, analyze, and transform images
- 🎬 **Video Generation & Processing** — AI-powered video generation, editing, and understanding
- 🎙️ **Audio, Speech & Music** — speech recognition, text-to-speech, music generation, podcasts, and voice processing
- 📄 **Document Intelligence** — analyze, summarize, translate, compare, search, and understand PDFs, Office documents, spreadsheets, and other files
- 👁️ **Vision AI** — image understanding, OCR, object detection, and multimodal reasoning
- 🚗 **Autonomous Intelligence** — planning, decision-making, and motion command generation for cars, robots, drones, boats, and other autonomous platforms
- 📊 **Data Analytics** — visualization, dashboards, chart generation, and AI-assisted insights
- 🔍 **Research Assistant** — AI-powered research, information synthesis, and knowledge discovery
- 🤖 **AI Agents** — planning, reasoning, memory, and multi-step task execution
- 🔄 **Workflow Automation** — reusable AI pipelines
- 🧠 **Local & Browser AI** — run supported models entirely on-device for privacy, offline use, and zero setup
- 🌐 **Multi-Provider AI** — cloud, browser, and local AI providers through one unified interface

## Getting Started

1. Open the app and choose a setup path: **Instant AI** (no key needed, fastest), **Cloud AI** (bring your own API key from OpenAI, Claude, Gemini, and more), or **Local AI** (runs entirely in your browser, works offline after the first download).
2. Explore the available modules from the navigation menu — each one includes contextual guidance.
3. You can change your provider setup at any time from Keys & Providers.

Most cloud AI features require a valid API key from the provider you choose. Without at least one configured provider — or a supported Browser AI / Local AI model — some capabilities won't be available.
